TSPulse Time Series Forecasting-Based Anomaly Detection

This folder contains experiments using TSPulse, a transformer-based time series forecasting model, to detect anomalies through prediction errors. The notebooks evaluate TSPulse on both carOBD and KIT datasets, including tests on artificially injected faults. This approach leverages forecasting residuals to identify when sensor behavior deviates from expected patterns, enabling robust anomaly detection across different driving conditions.
