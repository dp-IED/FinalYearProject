GDN-Based Anomaly Detection Experiments

This folder contains experiments using Graph Deviation Networks (GDN) for anomaly detection in OBD-II sensor data. GDN learns graph structures between sensors and uses them to identify anomalous patterns. The GNNAD.ipynb notebook explores different GDN configurations and loss functions applied to carOBD and KIT datasets. Visualization files show the learned adjacency matrices and network representations of anomalous states discovered by the model.
